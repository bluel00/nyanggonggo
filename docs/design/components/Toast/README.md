`Toast` is a `text`-filled message pinned to the column bottom above the safe area (in the app: sonner via `Toaster`/`showToast`). Consumer provides `visible` and `message`. The display time is not set separately: the app uses the sonner default (about 4 seconds). Messages: "링크가 복사됐어요" ([링크 복사] in the detail CTA bar), "카카오톡을 열지 못해 링크를 복사했어요" (Kakao sharing failed, so the link was copied instead), "공유에 실패했어요. 링크로 대신 공유해보세요" (copying the link itself failed: after a Kakao failure, on [링크 복사], or when the share sheet fails for a reason other than the person closing it; code `SHARE_MESSAGES.failed`), "관심 공고에 담았어요", "관심 공고에서 뺐어요". Distance from the column bottom is `toast-offset`, `space-6` (24px). On screens with a bottom CTA (the detail page) the code computes it above the CTA (now `bottom-cta-h` + `space-3` = 80px). The safe area is added on top. Positioned inside the column, not the viewport.
