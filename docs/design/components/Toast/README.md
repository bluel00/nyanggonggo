`Toast` is a `text`-filled message pinned to the column bottom above the safe area (in the app: sonner via `Toaster`/`showToast`). Consumer provides `visible` and `message`, hides it after about 2 seconds. Messages: "링크가 복사됐어요", "공유에 실패했어요. 링크로 대신 공유해보세요", "관심 공고에 담았어요", "관심 공고에서 뺐어요". Distance from the bottom is `toast-offset`: `space-6` by default, and on the detail page `bottom-cta-h` + `space-3` (80px) so it sits above the CTA bar; the safe area is added on top. Positioned inside the column, not the viewport.
