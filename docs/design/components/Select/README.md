`Select` is the native select styled for 지역 (in the app: `NativeSelect`). The filter sheet uses two: 시/도 ("전체 시/도" for all) and 시/군/구 ("전체 시/군/구"). Changing 시/도 resets 시/군/구 to 전체; when a 시/도 has no 시/군/구 (세종) the second Select is disabled. The region list is static. Consumer provides `options`, `value`, `onChange`, `label` (aria-label), optional `disabled`. Keeps the native picker on iOS and Android. Values are codes in the URL (`region`, `district`), labels are mapped in the UI.
