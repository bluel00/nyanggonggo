`Icon` draws the 1.8px-stroke outline icons in `currentColor`: `heart`, `filter`, `close`, `back`, `chevron-down`, `map-pin`, `phone`, `image-off`, `info`. The app has no Icon component: it uses lucide icons directly (Heart, SlidersHorizontal, X, ChevronLeft, ChevronDown, MapPin, Phone, ImageOff, Info); these are placeholders for them. Info, MapPin and Phone are 14px in the small text buttons ([보호소 정보], [지도], [전화]); ImageOff stands in for a missing or failed photo. Consumer provides `name`, optional `size` (default 22) and `filled` (heart only). Always place it inside a labelled control (`aria-label` on the button) or next to its word; the icon itself is aria-hidden. Never colour it with a status colour.
