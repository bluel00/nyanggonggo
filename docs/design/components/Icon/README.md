`Icon` draws the 1.8px-stroke outline icons in `currentColor`: `heart`, `filter`, `close`, `back`, `chevron-down`, `chevron-right`, `map-pin`, `phone`, `image-off`, `info`, `share`, `link`. The app has no Icon component: it uses lucide icons directly (Heart, SlidersHorizontal, X, ChevronLeft, ChevronDown, ChevronRight, MapPin, Phone, ImageOff, Info, Share2, Link); these are placeholders for them. Info, MapPin and Phone are 14px in the small text buttons ([보호소 정보], [지도], [전화]); ImageOff stands in for a missing or failed photo. ChevronRight (`chevron-right`) is 20px in `text-2` on the home 기타 동물 card (#87). `share` (three linked dots, lucide Share2, not Share) and `link` (lucide Link) are 18px in the second share button of the detail CTA bar: "다른 앱으로 공유" and "링크 복사" (see `ShareButton`). Consumer provides `name`, optional `size` (default 22) and `filled` (heart only). Always place it inside a labelled control (`aria-label` on the button) or next to its word; the icon itself is aria-hidden. Never colour it with a status colour.
