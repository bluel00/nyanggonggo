`ShareButton` is the share action in the fixed detail CTA bar, in two forms: the Kakao primary (default) and a second share button (`variant="other"`). The bar reads [`FavoriteButton`] [카카오톡 공유] [second share button]; the bar ground (`bg` + `shadow-bar`), its padding and the 8px gaps are unchanged. Chosen 2026-10-27 from the design board "상세 하단 바 · 다른 앱으로 공유 시안 1–3" (draft 2).

- **Kakao (default).** Kakao Yellow (`kakao` / `on-kakao`), the only non-status accent, label "카카오톡 공유" at `card-title` 16px with the chat bubble. It is the primary, one-tap action and takes all the remaining width. Its side padding is `space-2` so both buttons fit at 375 wide. Consumer provides `onClick`. On Kakao SDK failure or no support, the caller copies the link and shows `Toast` "카카오톡을 열지 못해 링크를 복사했어요" (a different message from the [링크 복사] button's "링크가 복사됐어요"). Do not use the yellow for any other action.
- **Second share button (`variant="other"`).** A white pill in the same material as `FavoriteButton` (`surface`, `shadow-control`, no outline), as wide as its content: 18px icon + 6px + label at 14px/600 `text`, side padding `space-3`, 44 high. Consumer provides `onClick` and `canShare`. `canShare` comes from whether the browser supports the share sheet (Web Share), not from the kind of device. The label and icon change together with what happens:
  - `canShare` true (the OS share sheet can open, Web Share): "다른 앱으로 공유" with the `share` icon (three linked dots). Pressing it opens the OS share sheet (X, Instagram DM, messages, copy link …). If the person just closes the sheet, no toast is shown.
  - `canShare` false (some desktop browsers): "링크 복사" with the `link` icon. Pressing it copies the link and shows `Toast` "링크가 복사됐어요". The button gets narrower, so Kakao gets wider.
- **Accessibility.** The visible label is the accessible name (no separate `aria-label`); the icon is hidden. Both buttons are 44 high or more.
- **Ended notices** use the same bar; favourite and share stay active.
- **Motion.** Press is the same as the heart and Kakao buttons: `press-scale` over `press-duration`; the white pill's ground goes to `bg` while pressed, like `FavoriteButton`. Reduced motion: no effect.
- **Sizes on the board** (Kakao : second button): 390 wide 159 : 139, 375 wide 144 : 139; with "링크 복사" 198 : 100 and 183 : 100.
- In the code the second button is `ShareSheetButton` (`features/animal-share`, #94, PR #95); it matches this design, only the name differs (see `handoff.md` (b), name table).
