`TextButton` is an action drawn as text, with no container (2026-11-10, `handoff.md` (l)). It is a separate component from `Button`, as in Toss TDS (TextButton is built on text, Button on a container). Consumer provides `children` (label), optional `icon` (14px, before the label; TextButton sets its size), `variant`, `size`, `disabled`, `onClick`, and `aria-label` when the label alone does not say what happens. In the app a link is the consumer's own `<a>` passed with `asChild`, the same way as Button (PR #128); the icon, label and arrow are placed inside it. This preview's `href` (+ `external`) only stands in for that.

- **Look**: label at weight 600 in `text`; icon 14px before it, 2px gap.
- **Sizes** (2026-11-11, `handoff.md` (m)), named after the type styles: `caption` (12/16, the default: the row-end actions [보호소 정보], [지도], [전화]) and `body` (14/20, for a text action that sits on a line of `body` text, so the two read as one line: the 관심 공고 partial-error [다시 시도]). The icon stays 14px in both until a `body` action needs one.
- **Variants** (as TDS): `underline` (default here): a 1px underline under the label only, 3px below the text; `arrow`: no underline, ChevronRight 14px after the label (use it for "more" or "go to", not for opening another app or a phone call); `clear`: no cue, only where the whole context already reads as tappable. A text action next to plain text must never be `clear`: that was the [보호소 정보] problem.
- **States**: pressed, and hover on devices that can hover (`@media (hover: hover)`), turn the label `text-2`; no scale. Disabled (2026-11-11; a `<button>` only, e.g. [다시 시도] while the retry is running): label and icon in `text-disabled`, the underline stays, no pressed or hover change, not clickable. Focus: 2px `focus-ring`, 2px offset. Colour changes are not motion, so reduced motion keeps them.
- **Hit area** 44×44 while the text keeps its line height, so a row does not grow (in the app: `min-h-11 min-w-11` with `-my-3`).
- **Used for** [보호소 정보] (info) on the detail's 보호소 row, [지도] (map pin, new tab) and [전화] (phone, `tel:`) in the shelter info sheet, and [다시 시도] at the end of the 관심 공고 partial-error line (no icon, `body` size; 2026-11-11, `handoff.md` (m)), all `underline`. Each carries its own accessible name where the label is not enough.
