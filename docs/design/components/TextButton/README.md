`TextButton` is an action drawn as text, with no container (2026-11-10, `handoff.md` (l)). It is a separate component from `Button`, as in Toss TDS (TextButton is built on text, Button on a container). Consumer provides `children` (label), optional `icon` (14px, before the label), `variant`, `onClick`, or `href` (+ `external` for a new tab) to render a link, and `aria-label` when the label alone does not say what happens.

- **Look**: label `caption` size (12/16) at weight 600 in `text`; icon 14px before it, 2px gap. One size for now.
- **Variants** (as TDS): `underline` (default here): a 1px underline under the label only, 3px below the text; `arrow`: no underline, ChevronRight 14px after the label (use it for "more" or "go to", not for opening another app or a phone call); `clear`: no cue, only where the whole context already reads as tappable. A text action next to plain text must never be `clear`: that was the [보호소 정보] problem.
- **States**: pressed, and hover on devices that can hover (`@media (hover: hover)`), turn the label `text-2`; no scale. Focus: 2px `focus-ring`, 2px offset. Colour changes are not motion, so reduced motion keeps them.
- **Hit area** 44×44 while the text keeps its line height, so a row does not grow (in the app: `min-h-11 min-w-11` with `-my-3`).
- **Used for** [보호소 정보] (info) on the detail's 보호소 row, [지도] (map pin, new tab) and [전화] (phone, `tel:`) in the shelter info sheet, all `underline`. Each carries its own accessible name.
