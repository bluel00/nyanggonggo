`Chip` is a pill toggle for the filter sheet's two chip groups: 보호 상태 (보호중, 종료, 전체; default 보호중) and 성별 (전체, 암컷, 수컷; default 전체 — animals with unknown sex appear only under 전체). Consumer provides `selected`, `onClick`, `children`. Unselected is `surface` with `shadow-chip` and no visible outline; selected is `text` fill with an `on-text` label and no shadow. 36px tall, hit area extended to 44px. Selection values come from the URL search params (`status`, `sex`), not local state. The list header's filter button shares this shape but has its own shadow and state; see `FilterButton`.
