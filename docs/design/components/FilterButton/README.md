`FilterButton` is the list header's [필터] button (in the app it lives in `features/animal-filter`, not `shared/ui`). It uses the Chip shape with a 16px filter icon and the label 필터. Unselected is `surface` with `shadow-control` (not `shadow-chip`). When a sex (암컷 / 수컷) is chosen it takes the selected Chip look (`text` fill, `on-text` label, no shadow) and its accessible name becomes "필터, 암컷" / "필터, 수컷". Consumer provides `sexLabel` (omit for 전체) and `onClick`. No other filter condition is shown on the button, and there is no filter summary above the list (undecided). Pressed: `press-scale`.
