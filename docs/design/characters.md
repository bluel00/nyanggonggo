# 캐릭터

고양이·강아지 캐릭터 한 쌍. 홈(축종 선택)에서 처음 쓰고, 이후 사진이 없는 화면에 넓혀 쓸 수 있다. 원본 시안은 Design 아티팩트 "냥공고 홈 · 축종 선택"에 있다. 고양이는 EL의 고양이 "햅격이"가 모델이다.

파일: `assets/Characters/nyang-cat.svg`, `assets/Characters/nyang-dog.svg` (각 120×120)

## 어디에 쓰나

| 화면 | 허용 |
|---|---|
| 사진이 없는 화면 (홈, 빈 상태, 결과 없음, 에러, 404) | 캐릭터를 두고, 대기 동작을 계속하되 드물게 |
| 사진이 있는 화면 (목록, 상세, 찜 목록) | 사용자가 누른 직후의 짧은 반응만 (약 1초 이내, 끝나면 정지) |
| 종료 공고와 관련된 화면·맥락 (종료 공고 상세, 종료 필터 목록) | 캐릭터를 쓰지 않음 |

- 사진이 주인공이다. 캐릭터가 실제 고양이·강아지 사진과 시선을 다투지 않게 한다.
- 캐릭터는 장식이다. `aria-hidden`으로 두고 의미는 텍스트 라벨("고양이", "강아지")이 전한다.
- 기타 동물 캐릭터는 없다. 기타는 종이 분산되어 하나로 대표할 수 없다.

## 그리기 규칙

- 1:1 크기(120px)에서 선이 1.8px로, 아이콘과 같은 굵기다. 크기를 바꿀 때는 비율로만 키운다.
- 평면 채색, 그림자·그라디언트·필터·마스크·클리핑·텍스트 없음. path와 채색만.
- 상태색(`status-*`)과 카카오 노랑은 쓰지 않는다.

## 일러스트 팔레트

일러스트 전용이다. UI 요소(텍스트, 배경, 테두리)에는 쓰지 않는다.

| 색 | 쓰임 |
|---|---|
| `#111111` | 선, 눈 (`text`와 같음) |
| `#A38D74` | 고양이 털 |
| `#4A3E34` | 고양이 고등어 줄무늬 |
| `#FFFFFF` | 고양이 발·턱·가슴 |
| `#D9B3A6` | 고양이 귀 안쪽 |
| `#C48B7D` | 고양이 코 |

| `#9C3548` | 고양이 리본 (크랜베리) |

## 그룹과 기준점 (Rive용)

움직이는 그룹은 `translate` 값이 곧 회전 기준점이고, 안의 path는 그 점 기준 좌표다. `eyes-closed`, `eyes-happy`는 `opacity="0"`으로 들어 있다.

| 그룹 | 기준점 (120×120 좌표) | 쓰임 |
|---|---|---|
| `cat` / `dog`, `body` | 바닥 가운데 (60, 112) | 숨쉬기, 눌림 때 납작 |
| `tail` | 꼬리 뿌리 (고양이 86,106 / 강아지 84,104) | 흔들기 |
| `head` | 목 (60, 74) | 갸웃 |
| `ear-left`, `ear-right` | 고양이: 귀 밑동 (45,40 / 75,40), 강아지: 귀 붙는 곳 (40,38 / 80,38) | 고양이 쫑긋, 강아지 펄럭 |
| `eyes-open`, `eyes-closed`, `eyes-happy` | 두 눈 가운데 (고양이 60,52 / 강아지 60,49) | 깜빡임, 눌림 눈 |
| `bow` (고양이만) | 목 (60, 76) | 머리와 따로 살랑 |

Rive로는 Rive CLI(RML)에서 SVG path를 옮겨 만든다. 고양이는 2026-10-08 실험에서 모양·그룹·기준점이 원본과 같게 옮겨졌다(저장소 `docs/architecture.md` 12절 47). Rive 편집기로 직접 가져오는 경로는 확인하지 않았다.

## 모션

상태는 넷이다. 이름은 Rive 상태 머신과 앱 코드에서 그대로 쓴다.

| 상태 | 언제 | 동작 |
|---|---|---|
| `greet` 인사 | 화면에 들어올 때 1회 | 제자리에서 폴짝 뛰며 한 바퀴. 고양이와 강아지는 엇갈려서(동시에 뛰지 않음). 끝나면 `idle` |
| `idle` 대기 | 평소 | 계속하되 드물게. 4~6초에 한 번 깜빡임(`eyes-open` 세로로 접힘 → `eyes-closed`), 아주 약한 숨쉬기(바닥 기준 1~2%), 꼬리 살랑(작고 느리게, 계속), 고양이 리본 가끔 살랑. 고양이와 강아지는 박자를 엇갈린다 |
| `sleep` 잠 | 아무 입력 없이 약 10초가 지나면 | 꾸벅 졸다가 엎드려 잠. 눈 감고 천천히 숨쉬기, 가끔 꼬리. **엎드린 포즈 그림이 필요해 아직 미구현** |
| `press` 반응 | 누를 때 | 250ms 이내: 눈 `eyes-happy`, 머리 6° 갸웃, 몸이 바닥 기준으로 살짝 납작. 다음 화면으로 바로 이동(이동을 늦추지 않는다). `sleep` 중이었으면 깨면서 같은 반응 |

- 누를 때 반응을 짧게 두는 이유: 홈 선택지는 누르면 바로 다음 화면으로 넘어간다. 긴 동작(점프 등)은 보이기 전에 화면이 바뀌거나, 보여 주려면 이동을 늦춰야 한다. 그래서 긴 동작은 `greet`로 둔다.
- `sleep`은 오래 머무를수록 움직임이 줄어들게 하는 장치이기도 하다("계속하되 드물게").
- 앱이 보내는 신호는 `press` 하나다(Rive 데이터 바인딩의 뷰 모델 트리거). `greet`·`idle`·`sleep` 전환은 Rive 상태 머신 안에서 처리한다.
- **reduced-motion**: 모든 동작을 끄고 기본 포즈로 정지(앱에서 처리).
- 지금 앱은 정지 SVG(`<img>`)다. 움직임은 Rive 적용 단계에서 입힌다.
