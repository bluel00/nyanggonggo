# 캐릭터

고양이·강아지 캐릭터 한 쌍. 홈(축종 선택)에서 처음 쓰고, 이후 사진이 없는 화면에 넓혀 쓸 수 있다. 원본 시안은 Design 아티팩트 "냥공고 홈 · 축종 선택"(Turnaround, LieSide, LegRig 시트)에 있다. 고양이는 EL의 고양이 "햅격이"가 모델이다.

파일 (각 120×120, 모두 오른쪽을 본다. 왼쪽은 루트를 좌우 반전해서 쓴다):

| 뷰 | 고양이 | 강아지 | 쓰임 |
|---|---|---|---|
| 정면 앉음 (기본) | `nyang-cat.svg` | `nyang-dog.svg` | 정지 그림, idle, press |
| 3/4 | `nyang-cat-34.svg` | `nyang-dog-34.svg` | greet 회전, 눕기 시작 |
| 옆 앉음 | `nyang-cat-side.svg` | `nyang-dog-side.svg` | greet 회전 |
| 뒤 | `nyang-cat-back.svg` | `nyang-dog-back.svg` | greet 회전 꼭대기 |
| 기우는 중간 | `nyang-cat-lie-mid.svg` | `nyang-dog-lie-mid.svg` | 눕기 |
| 옆으로 누움 | `nyang-cat-lie.svg` | `nyang-dog-lie.svg` | sleep |

- 경로: `assets/Characters/`.
- 정면 앉음은 다리 그룹만 나눴고 보이는 그림은 이전과 픽셀 단위로 같다.
- 엎드려 자는 정면 포즈(이전 `sleep` A안 "턱 괴기", `nyang-*-sleep.svg`)는 옆으로 눕기로 대체되어 폐기했다.

## 어디에 쓰나

| 화면 | 허용 |
|---|---|
| 사진이 없는 화면 (홈, 빈 상태, 결과 없음, 에러, 404) | 캐릭터를 두고, 대기 동작을 계속하되 드물게 |
| 사진이 있는 화면 (목록, 상세, 찜 목록) | 사용자가 누른 직후의 짧은 반응만 (약 1초 이내, 끝나면 정지) |
| 종료 공고와 관련된 화면·맥락 (종료 공고 상세, 종료 필터 목록) | 캐릭터를 쓰지 않음 |

- 사진이 주인공이다. 캐릭터가 실제 고양이·강아지 사진과 시선을 다투지 않게 한다.
- 캐릭터는 장식이다. `aria-hidden`으로 두고 의미는 텍스트 라벨("고양이", "강아지")이 전한다.
- 기타 동물 캐릭터는 없다. 기타는 종이 분산되어 하나로 대표할 수 없다.

## 그리기 규칙

- 1:1 크기(120px)에서 선이 1.8px로, 아이콘과 같은 굵기다. 크기를 바꿀 때는 비율로만 키운다.
- 평면 채색만 쓴다. 그림자·그라디언트·필터·마스크·클리핑·텍스트는 쓰지 않는다. path와 채색만.
- 상태색(`status-*`)과 카카오 노랑은 쓰지 않는다.

## 일러스트 팔레트

일러스트 전용이다. UI 요소(텍스트, 배경, 테두리)에는 쓰지 않는다.

| `#4A3E34` | 고양이 고등어 줄무늬 |
| `#FFFFFF` | 고양이 발·턱·가슴 |
| `#D9B3A6` | 고양이 귀 안쪽 |
| `#C48B7D` | 고양이 코 |
| `#D7AE9F` | 고양이 볼 |
| `#9C3548` | 고양이 리본 (크랜베리) |
| `#D9C8B2` | 강아지 털 |
| `#A68F76` | 강아지 귀 |

## 그룹과 기준점 (Rive용)

움직이는 그룹은 `translate` 값이 곧 회전 기준점이고, 안의 path는 그 점 기준 좌표다. `eyes-closed`, `eyes-happy`는 `opacity="0"`으로 들어 있다. 뷰마다 기준점 값이 다르고, 정확한 값은 각 SVG의 transform이 기준이다. 아래는 정면 앉음 값이다.

| 그룹 | 기준점 (정면, 120×120 좌표) | 쓰임 |
|---|---|---|
| `cat` / `dog`, `body` | 바닥 가운데 (60, 112) | 숨쉬기, 눌림 때 납작, 점프 높이 |
| `tail` | 꼬리 뿌리 | 흔들기 |
| `head` | 목 (60, 74) | 갸웃, 꾸벅 |
| `ear-left`, `ear-right` | 귀 밑동 | 고양이 쫑긋, 강아지 펄럭 |
| `eyes-open`, `eyes-closed`, `eyes-happy` | 두 눈 가운데 | 깜빡임, 눌림 눈, 잠 |
| `bow` (고양이만) | 목 | 머리와 따로 살랑 |
| `leg-*` | 관절(어깨·엉덩이) | 웅크림, 공중에서 뻗기, 착지, 눕기 |

**다리 그룹** (뷰마다 보이는 다리만 있다)

| 뷰 | 그룹 |
|---|---|
| 정면 | `leg-front-left`, `leg-front-right` |
| 뒤 | `leg-hind-left`, `leg-hind-right` |
| 3/4, 옆, 기우는 중간, 누움 | `leg-front-far`, `leg-front-near`, `leg-hind-near` |

- 각 다리 그룹 안에는 `-shaft`(관절 원 + 발까지 이어지는 면, 선 없음), `haunch-line`(뒷다리 near만), `-paw`가 들어 있다. 관절이 원이라 돌려도 몸통과 사이가 벌어지지 않는다.
- 그리는 순서: far 다리는 `body` 아래, near 다리는 위. 예외로 강아지 3/4는 먼 앞다리가 몸 안쪽의 선이라 셋 다 `body` 위에 있다.
- 회전 부호: SVG·Rive는 y가 아래로 커져서 +각도가 시계 방향이다. 오른쪽을 보는 옆모습에서 앞다리를 앞으로 뻗으려면 −, 뒷다리를 뒤로 뻗으려면 +다.
- 회전 범위: 시트에서 ±35°까지 확인했다. 그 각도에서는 고양이 앞다리의 흰 면이 몸 밖으로 나와 윤곽선 없이 보이므로, 오래 머무는 자세는 ±25° 안에서 쓴다. 한두 프레임만 스쳐 가는 공중 자세는 ±35°까지 쓸 수 있다.

**보간 가능 구간.** 옆 앉음·기우는 중간·누움 세 파일은 같은 id의 path가 명령 순서·점 개수까지 같다(다리 그룹 포함). 그래서 Rive에서 정점 키프레임으로 이어서 바꿀 수 있다. 정면·3/4·뒤는 구조가 달라서 그림 교체(hold)로만 바꾼다.

**그리는 순서 변경.** 누움에서는 `tail`이 몸 앞으로 감기므로 `body`와 다리 다음에 그린다. 옆 앉음과 기우는 중간에서는 맨 먼저 그린다. 기우는 중간 → 누움 사이에 꼬리 순서를 한 번 바꿔야 한다.

Rive로는 Rive CLI(RML)에서 SVG path를 옮겨 만든다. 정면 고양이는 2026-10-08 실험에서 모양·그룹·기준점이 원본과 같게 옮겨졌다(저장소 `docs/architecture.md` 12절 47). 그림 교체, 정점 보간, 그리는 순서 변경이 RML에서 되는지는 아직 확인하지 않았다.

## 모션

상태는 넷이다. 이름은 Rive 상태 머신과 앱 코드에서 그대로 쓴다.

| 상태 | 언제 | 동작 |
|---|---|---|
| `greet` 인사 | 화면에 들어올 때 1회 | 제자리에서 폴짝 뛰며 몸을 한 바퀴 돌린다(아래 "폴짝 돌기"). 고양이와 강아지는 엇갈려서(동시에 뛰지 않음). 끝나면 `idle` |
| `idle` 대기 | 평소 | 계속하되 드물게. 4~6초에 한 번 깜빡임(`eyes-open` 세로로 접힘 → `eyes-closed`), 아주 약한 숨쉬기(바닥 기준 1~2%), 꼬리 살랑(작고 느리게, 계속), 고양이 리본 가끔 살랑. 고양이와 강아지는 박자를 엇갈린다 |
| `sleep` 잠 | 아무 입력 없이 약 10초가 지나면 | 졸다가 옆으로 누워 잔다(아래 "잠 동작") |
| `press` 반응 | 누를 때 | 250ms 이내: 눈 `eyes-happy`, 머리 6° 갸웃, 몸이 바닥 기준으로 살짝 납작. 다음 화면으로 바로 이동(이동을 늦추지 않는다). `sleep` 중이었으면 200ms 안에 정면 앉음으로 튀어 오르며 같은 반응 |

**폴짝 돌기** (`greet`, 24fps 기준 약 0.83초)

| 구간 | 그림 | 프레임 | 시간 | 동작 |
|---|---|---|---|---|
| 움츠림 | 정면 | 3 | 125ms | 바닥 기준 세로 0.9로 납작. 앞다리 살짝 벌림 |
| 도약·회전 | 정면 1 → 3/4 2 → 옆 2 → 뒤 3 → 옆(반전) 2 → 3/4(반전) 2 → 정면 1 | 13 | 540ms | 꼭대기(뒤)에서 약 16px 위. 그림은 보간 없이 바꾸고 높이만 곡선. 공중에서는 세로로 늘이고 다리를 뻗는다 |
| 착지 | 정면 | 4 | 165ms | 납작 → 원래대로, 꼬리 한 번 살랑 |

- 귀·꼬리·리본은 몸보다 한 박자 늦게 따라온다(follow-through).
- 60fps로 옮기면 각 프레임 수 × 2.5.

**잠 동작** (약 10초 무입력부터)

| 구간 | 시간 | 동작 |
|---|---|---|
| 졸기 | 약 1.5초 | `eyes-open`을 세로 40%로 반쯤 접고, 머리가 3px쯤 꾸벅(회전 없이 아래로) 두 번 |
| 정면 → 3/4 | 150ms | 그림 교체. 머리를 살짝 숙이며 돌아섬 |
| 3/4 → 기우는 중간 | 250ms | 그림 교체. 중간 안에서 머리 0→10°, 꼬리 0→−15° 보간. 눈은 여기서 감김 |
| 기우는 중간 → 누움 | 600ms ease-out | 정점 보간. 몸통·다리·머리 위치가 누움으로, 꼬리는 뒤에서 앞으로 감김 |
| 잠 | 계속 | 숨쉬기 4초 주기(몸통 세로 1 → 1.02, 바닥 기준), 머리 1px 따라 오르내림. 꼬리 끝 10~15초에 한 번 ±6°. 리본 정지 |

- 고양이·강아지는 숨 박자를 엇갈린다.

**공통 규칙**
- 누를 때 반응을 짧게 두는 이유: 홈 선택지는 누르면 바로 다음 화면으로 넘어간다. 긴 동작(점프 등)은 보이기 전에 화면이 바뀌거나, 보여 주려면 이동을 늦춰야 한다. 그래서 긴 동작은 `greet`로 둔다.
- `sleep`은 오래 머무를수록 움직임이 줄어들게 하는 장치이기도 하다("계속하되 드물게").
- 무입력 시간은 화면에 머문 시간 기준이다. Rive 상태 머신이 시간으로 전환하고, 앱은 `press` 외에 신호를 보내지 않는다.
- 앱이 보내는 신호는 `press` 하나다(Rive 데이터 바인딩의 뷰 모델 트리거). `greet`·`idle`·`sleep` 전환은 Rive 상태 머신 안에서 처리한다.
- **reduced-motion**: 모든 동작을 끄고 정면 앉음으로 정지(앱에서 처리).
