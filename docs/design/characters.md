# 캐릭터

고양이·강아지 캐릭터 한 쌍. 홈(축종 선택)에서 처음 쓰고, 이후 사진이 없는 화면에 넓혀 쓸 수 있다. 원본 시안은 Design 아티팩트 "냥공고 홈 · 축종 선택"에 있다. 고양이는 EL의 고양이 "햅격이"가 모델이다.

파일: `assets/Characters/nyang-cat.svg`, `assets/Characters/nyang-dog.svg` (각 120×120)

## 어디에 쓰나

| 화면 | 허용 |
|---|---|
| 사진이 없는 화면 (홈, 빈 상태, 결과 없음, 에러, 404) | 캐릭터를 두고, 대기 동작을 계속하되 드물게 |
| 사진이 있는 화면 (목록, 상세, 찜 목록) | 사용자가 누른 직후의 짧은 반응만 (약 1초 이내, 끝나면 정지) |
| 종료 공고와 관련된 화면·맥락 (종료 공고 상세, 종료 필터 목록) | 캐릭터를 쓰지 않음 |

- 사진이 주인공이다. 캐릭터가 실제 고양이·강아지 사진과 시선을 다투지 않게 한다.
- 캐릭터는 장식이다. `aria-hidden`으로 두고 의미는 텍스트 라벨("고양이", "강아지")이 전한다.
- 기타 동물 캐릭터는 없다. 기타는 종이 분산되어 하나로 대표할 수 없다.

## 그리기 규칙

- 1:1 크기(120px)에서 선이 1.8px로, 아이콘과 같은 굵기다. 크기를 바꿀 때는 비율로만 키운다.
- 평면 채색, 그림자·그라디언트·필터·마스크·클리핑·텍스트 없음. path와 채색만.
- 상태색(`status-*`)과 카카오 노랑은 쓰지 않는다.

## 일러스트 팔레트

일러스트 전용이다. UI 요소(텍스트, 배경, 테두리)에는 쓰지 않는다.

| 색 | 쓰임 |
|---|---|
| `#111111` | 선, 눈 (`text`와 같음) |
| `#A38D74` | 고양이 털 |
| `#4A3E34` | 고양이 고등어 줄무늬 |
| `#FFFFFF` | 고양이 발·턱·가슴 |
| `#D9B3A6` | 고양이 귀 안쪽 |
| `#C48B7D` | 고양이 코 |
| `#D7AE9F` | 고양이 볼 |
| `#9C3548` | 고양이 리본 (크랜베리) |
| `#D9C8B2` | 강아지 털 |
| `#A68F76` | 강아지 귀 |
| `#BFA88E` | 강아지 눈 얼룩 |
| `#F7F3EE` | 강아지 배·주둥이 |
| `#EBD7CA` | 강아지 볼 |

**리본 예외.** "색 포인트는 곧 상태"의 두 번째 예외다(첫 번째는 ShareButton의 `kakao`). 리본 빨강은 캐릭터 시그니처로만 쓰고 다른 곳에 퍼뜨리지 않는다. `#9C3548`은 푸른 기가 있어 임박 주황(`status-soon`)과 구분된다.

## 그룹과 기준점 (Rive용)

움직이는 그룹은 `translate` 값이 곧 회전 기준점이고, 안의 path는 그 점 기준 좌표다. `eyes-closed`, `eyes-happy`는 `opacity="0"`으로 들어 있다.

| 그룹 | 기준점 (120×120 좌표) | 쓰임 |
|---|---|---|
| `cat` / `dog`, `body` | 바닥 가운데 (60, 112) | 숨쉬기, 눌림 때 납작 |
| `tail` | 꼬리 뿌리 (고양이 86,106 / 강아지 84,104) | 흔들기 |
| `head` | 목 (60, 74) | 갸웃 |
| `ear-left`, `ear-right` | 고양이: 귀 밑동 (45,40 / 75,40), 강아지: 귀 붙는 곳 (40,38 / 80,38) | 고양이 쫑긋, 강아지 펄럭 |
| `eyes-open`, `eyes-closed`, `eyes-happy` | 두 눈 가운데 (고양이 60,52 / 강아지 60,49) | 깜빡임, 눌림 눈 |
| `bow` (고양이만) | 목 (60, 76) | 머리와 따로 살랑 |

Rive로 가져올 때 그룹 구조·기준점·`opacity 0` 그룹이 유지되는지는 아직 확인하지 않았다. 첫 가져오기에서 확인한다.

## 모션

- **대기 (사진 없는 화면)**: 계속하되 드물게. 4~6초에 한 번 깜빡임(`eyes-open` 세로로 접힘 → `eyes-closed`), 아주 약한 숨쉬기, 가끔 꼬리 한 번. 고양이와 강아지는 박자를 엇갈려 동시에 움직이지 않게 한다.
- **눌렸을 때**: 버튼이 0.98로 줄어드는 100ms 동안 눈이 `eyes-happy`로 바뀌고, 머리 6° 갸웃, 몸이 바닥 기준으로 살짝 납작. 250ms ease-out으로 돌아온 뒤 다음 화면으로.
- **reduced-motion**: 모든 동작을 끄고 기본 포즈로 정지.
- 1차 구현은 정지 SVG다. 움직임은 Rive 단계에서 입힌다.
