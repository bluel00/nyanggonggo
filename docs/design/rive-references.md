# Rive 참고 작품 분석

캐릭터 턴어라운드(3/4·옆·뒤)와 옆으로 눕는 잠 포즈 그림이 나오면 "폴짝 뛰며 몸 돌리기"(greet)와 "옆으로 드러누워 자기"(sleep)를 만든다. 그 전에 공개된 Rive 작품에서 **타이밍과 기법만** 배운다. 그림·에셋은 가져오지 않는다(우리 캐릭터만 쓴다). 동작의 기준은 `characters.md` 모션 절이고, 이 문서는 그 기준을 채울 수치 제안이다.

조사일 2026-10-08. 수치는 모두 60fps 프레임 기준이다(1프레임 = 16.7ms).

## 분석 방법

- **로그인 없이** 마켓플레이스 미리보기가 쓰는 공개 런타임 파일(`https://public.rive.app/community/runtime-files/<id>.riv`)을 받았다(14KB, 177KB, 7.7KB, 882KB).
- Rive CLI 1.5.0으로는 `.riv`를 RML로 되돌릴 수 없다. `rive create`는 편집기 `.rev`(`--from-rev`)나 내 계정의 파일(`--from-remote-file`, 로그인 필요)만 받고, `rive inspect`는 RML 프로젝트만 읽는다.
- 그래서 `.riv` 바이너리를 직접 읽었다. 파일 머리의 속성 목차(키마다 값 형식)로 모든 객체를 읽고, `rive schema --json`의 typeKey·속성 키로 이름을 붙였다(일회성 도구, 저장소에 넣지 않음). 애니메이션 트랙 1,158개 모두 대상 객체의 유형과 속성이 맞았다(어긋남 0). 구성 요소 이름은 내보낼 때 지워져 있어 번호와 유형으로 구분했다.
- 웹 런타임(`@rive-app/webgl2` 2.44.0)으로 재생하며 프레임을 캡처해 눈으로 확인했다(저장소 밖 `C:\side\nyanggonggo-review\rive-references\frames`).

## 1순위: Sleepy Cat - Falling Asleep Loop

700×600, 벡터만(이미지 없음). Node 37, Shape 50, ClippingShape 3, RootBone 1 + Bone 1(꼬리), 스킨·메시 없음.

### 상태 머신 `cat_controller`

입력 2개: Bool `is_hovering`, Trigger `tap_wake`. 레이어 4개가 동시에 돈다.

| 레이어 | 상태 흐름 | 비고 |
|---|---|---|
| Layer 1(본편) | Entry → blink → yawn → drowsy → curl_up → **sleep(반복)** → [`tap_wake`] → wake_up → stretch → blink 2 | 전환은 모두 exit time 100%(앞 애니메이션이 끝나면) |
| Layer 3 | breathe(반복) | 깨어 있을 때 숨쉬기 |
| Layer 2 | tail_wag(반복) | 꼬리 |
| Layer 4 | (빈 상태) ↔ ear_twich | `is_hovering`이 참이면 귀 떨기 |

리스너: 포인터 move/exit → `is_hovering`, 포인터 down → `tap_wake`.

### 단계별 타이밍(각 애니메이션은 60프레임 = 1초짜리 1회 재생)

| 단계 | 하는 일(프레임) | 기법 |
|---|---|---|
| blink | 눈꺼풀이 3f 동안 내려오고 3f 동안 올라감(100ms). 40~43f에 한 번 더 | 눈꺼풀 도형이 클리핑 안에서 y로 미끄러짐 |
| yawn | 0~20f 입 벌림(그림 켜짐), 20~35f 유지, 35~46f 닫힘. 같은 0~20f에 눈꺼풀이 반쯤 내려옴(가늘게 뜬 눈) | 입 그림 opacity 전환 + 눈꺼풀 y |
| drowsy | 0~15f 눈꺼풀이 더 처짐. 머리가 0 → 5°(26f) → 0(35f) → 10°(46f) → 5°(55f): **두 번 꾸벅, 두 번째가 더 크게** | 머리 그룹 회전 |
| curl_up | 0~25f 앉은 몸 전체(1 → 0.5 → 0)와 웅크린 몸 전체(0 → 0.5 → 1)를 **교차 페이드**, 25~30f 웅크린 몸 scaleY 0.98 → 1로 내려앉음. 0~15f 감은 눈 그림이 켜짐 | **그림 바꿔 끼우기(몸 전체)** + 작은 눌림 |
| sleep(반복) | 몸 scaleY 1 → 1.03(30f) → 1(60f): 1초 주기 숨쉬기. "Zzz" 묶음이 0~20f 나타나며 위로, 20~40f 사라지며 더 위로(y 93 → 33 → 13) | 단순 변형 |
| wake_up | 0~15f 웅크린 몸 → 앉은 몸 교차 페이드. 눈 그룹이 탄성 이징으로 y 40 → 0(0~15f, 튀어 오르듯). 머리 5° → -5°(15f) → 0(25f). "にゃ" 말풍선 | 그림 교체 + 탄성 |
| stretch | 몸 (1,1) → (0.95, 1.10)(16f, 길게 펴기, 10px 위로) → (1.05, 0.95)(30f, 눌림) → 1(45f). 머리는 몸과 반대로 움직여(16f 아래, 30f 위) 늦게 따라온다 | 스쿼시·스트레치 + 후속 동작 |
| breathe(깨어 있을 때) | 몸 scaleY 1 → 1.02 → 1, 머리 y +2px·1° 기울기(1초 주기) | 단순 변형 |
| tail_wag(반복, 46f) | 뿌리 뼈 -56° → -31°(15f) → -56°(30f) → -66°(46f), 끝 뼈가 반대로 조금 늦게 | **뼈 2개 사슬**, 탄성 이징 |
| ear_twich(15f) | 귀가 3f마다 y ±5px·3~5° 떨림 2번 | 단순 변형 |

- 이징은 대부분 **linear**이고, 탄성(Elastic, 기본값 easeOut·amplitude 1·period 1)은 꼬리와 깨어날 때 눈에만 쓴다.
- 잠들기까지 blink 1초 + yawn 1초 + drowsy 1초 + curl_up 1초 = **약 4초**.
- 캡처로 보면 교차 페이드 중에 두 몸이 반투명하게 겹쳐 보인다(curl_up·wake_up). 귀엽지만 겹침이 눈에 띈다.

### 다리

다리를 따로 나누지 않았다. 앉은 몸·웅크린 몸이 통째로 다른 그림이고, 그 사이를 교차 페이드로 바꾼다.

## 2순위: interactive cat animation(AnggaMotion)

아트보드 17개(본 화면 `Main` 2861×1614와 눈·입·머리 장식·상자 등 부품 아트보드). `Main`: RootBone 6 + Bone 11, Skin 17, Tendon 39(경로를 뼈로 휘는 벡터 스키닝, `CubicWeight` 94), NestedArtboard 22(눈·입 표정은 중첩 아트보드와 그 입력으로 바꾼다), Joystick 1(포인터 따라보기), TranslationConstraint 2, ClippingShape 11, 오디오 1. 이징은 **CubicValueInterpolator 41**(값 축 곡선), CubicEase 3, Elastic 3.

## 배울 점(공통)

1. **동시에 도는 레이어로 나눈다.** 본편 순서(잠들기·깨기)와 늘 도는 것(숨쉬기·꼬리·귀)을 다른 레이어에 둬서 본편이 바뀌어도 숨쉬기는 끊기지 않는다(Sleepy Cat 4개, rnkn 4개).
2. **후속 동작은 프레임 지연으로 만든다.** 사슬의 다음 마디를 앞 마디보다 늦게: 느린 대기 13~18프레임, 빠른 반응 2~5프레임. 끝으로 갈수록 크게(AnggaMotion).
3. **큰 자세 변화는 그림을 바꾼다.** 앉기 ↔ 웅크리기처럼 실루엣이 바뀌는 순간은 변형이 아니라 다른 그림이다(Sleepy Cat). 바꾸는 순간을 눌림·탄성 같은 움직임으로 감추면 겹침이 덜 보인다.
4. **고개 돌림은 시차로.** 얼굴 부품을 바깥 윤곽보다 크게 옮기면 회전 없이 돌아보는 느낌이 난다(AnggaMotion).
5. **짧게 반복하는 숨쉬기(1~2초)도 진폭이 작으면(2~3%) 거슬리지 않는다.** 단, 우리 `characters.md`의 대기는 "드물게"라 잠의 숨쉬기만 이 범위로 둔다.

## 우리 동작에 적용할 수치 제안(1·2순위 기준)

120px 캐릭터 기준, 60fps. 그림은 디자인에서 나올 턴어라운드(정면·3/4·옆·뒤)와 옆으로 누운 잠 포즈를 가정한다.

### greet: 폴짝 뛰며 몸 돌리기(약 0.9초, 지금 0.75초에서 늘림)

| 구간 | 프레임 | 내용 |
|---|---|---|
| 예비 동작 | 0~7 | 웅크림 scaleY 0.92 / scaleX 1.05(ease-out). 귀·꼬리는 3프레임 늦게 같은 방향으로 |
| 도약 | 7~11 | 늘어남 scaleY 1.06 / scaleX 0.97, 위로 출발 |
| 공중 | 11~31 | 위로 10px(ease-out으로 올라가고 ease-in으로 내려옴). 이 20프레임 안에서 **그림 바꾸기**: 정면 → 3/4 → 옆 → 뒤 → 옆(좌우 반전) → 3/4(반전) → 정면, 각 3프레임 **hold**(교차 페이드 없이 `Solo` 전환) |
| 착지 | 31~35 | 눌림 scaleY 0.94 / scaleX 1.05 |
| 안정 | 35~54 | 1로 복귀(ease-out). 꼬리·귀는 착지보다 3~5프레임 늦게 한 번 흔들리고 멈춤(AnggaMotion 반응 지연) |

- 그림을 바꾸기 직전 1~2프레임에 얼굴 부품을 돌 방향으로 2~3px 먼저 옮기면(바깥 윤곽은 1px) 돌기 시작이 부드럽다(시차).
- 강아지는 지금처럼 20프레임 늦게 시작한다.

### sleep: 졸기 → 옆으로 눕기(약 3.5초) → 잠(반복)

`characters.md`: 약 10초 입력이 없으면 시작. Sleepy Cat은 약 4초 걸린다.

| 단계 | 길이 | 내용 |
|---|---|---|
| 하품 | 60f(1초) | 0~20f 입 벌림 + 눈 가늘게, 20~35f 유지, 35~46f 닫힘(Sleepy Cat yawn) |
| 꾸벅 | 55f(약 0.9초) | 머리 0 → 5°(26f) → 0(35f) → 8~10°(46f) → 5°(55f), 눈꺼풀 처짐(Sleepy Cat drowsy) |
| 눕기 | 약 30f(0.5초) | 0~8f 몸을 낮춤(scaleY 0.95) → 8f에 **옆으로 누운 그림으로 바꿈**(hold, 낮아진 순간이라 바뀜이 덜 보인다) → 8~13f scaleY 0.98 → 13~20f 1로 내려앉음. 교차 페이드를 쓴다면 4프레임 이하(Sleepy Cat의 25프레임 페이드는 겹침이 보였다) |
| 잠(반복) | 주기 2.5~3초 | 몸 scaleY 1 → 1.025 → 1(Sleepy Cat은 1초·3%인데, 우리 대기 숨쉬기가 5초·1.5%라 그보다 느린 쪽이 "깊은 잠"으로 읽힌다). 꼬리는 10초쯤에 한 번 살짝(가끔) |

- Sleepy Cat의 "Zzz"는 `characters.md`의 "텍스트 없음" 규칙과 부딪힌다. 쓰려면 글자가 아닌 도형으로 그리고 디자인 결정을 받는다.
- 눈 감기는 Sleepy Cat처럼 클리핑 안의 눈꺼풀을 내리는 방식이 자연스럽지만, `characters.md`가 "클리핑 없음"이라 지금처럼 `eyes-open` 세로 접기 → `eyes-closed` 바꾸기를 쓴다.

### 깨기(잠 중 press)

- 홈에서는 누르면 바로 다음 화면으로 가므로 **250ms 안**(`characters.md` press 규칙): 0f에 앉은 그림 + `eyes-happy`로 바꾸고, 0~12f 탄성(Elastic easeOut) 눌림 → 1(Sleepy Cat wake_up의 15프레임 탄성), 머리 5° → -3° → 0.
- 화면을 떠나지 않는 곳에서 깨울 때만 기지개를 붙인다: (0.95, 1.10) 16f → (1.05, 0.95) 30f → 1 45f, 머리는 몸보다 2~4프레임 늦게(Sleepy Cat stretch).

## RML(Rive CLI 1.5.0)로 가능한 것과 안 되는 것

`rive schema`에서 아래 유형은 모두 RML로 쓸 수 있다(authorable).

| 기법 | RML 유형 | 우리에게 |
|---|---|---|
| 그림 바꿔 끼우기 | `Solo` + `KeyFrameId`(속성 296, hold) / opacity 키 | **턴어라운드·눕기에 쓴다.** 턴어라운드 그림마다 `Node`를 만들어 `Solo` 아래에 둔다 |
| 뼈 사슬 | `RootBone`, `Bone` | 가능. 뼈에 붙인 부품을 통째로 움직이는 데는 쉽다(꼬리·귀) |
| 경로 스키닝 | `Skin`, `Tendon`, `Weight`, `CubicWeight` | 쓸 수는 있지만 `rive docs rigging`이 "손으로 쓰기 가장 고통스러운 부분"이라며 편집기 `.rev`에서 가져오라고 한다(가중치를 정수로 묶어 쓰고, 결합 자세를 뼈 변환과 정확히 맞춰야 한다). 120px 평면 캐릭터에는 휘는 꼬리 정도만 고려 |
| 메시 변형 | `Mesh`, `MeshVertex` | 이미지용이라 벡터만 쓰는 우리에게는 필요 없다 |
| 클리핑 | `ClippingShape` | 가능하지만 `characters.md`가 금지 |
| 이징 | `CubicEaseInterpolator`, `CubicValueInterpolator`, `ElasticInterpolator` | 가능(탄성은 깨기·착지에) |
| 중첩 아트보드 | `NestedArtboard` | 가능. 지금은 필요 없다 |
| 포인터 따라보기 | `Joystick`, `ListenerAlignTarget` | 가능하지만 홈은 모바일 카드 누름뿐이고, 캐릭터 안에 리스너를 두지 않는다(앱 신호와 겹침) |
| 소리 | `AudioEvent` | 쓰지 않는다 |

- 지금의 변환기(`scripts/svg-to-rml.mjs`)는 `translate`만 지원한다. 턴어라운드 SVG도 같은 규칙(그룹 id·translate, path)으로 오면 그림마다 `--marker`로 넣을 수 있다. 좌우 반전은 그 그림 그룹의 `scaleX="-1"`로 만든다.
- 시차(얼굴 부품 이동)는 지금 그룹(`head` 아래 `eyes-*` 등)의 x를 키로 두면 된다.

## 남은 확인

- 턴어라운드·잠 포즈 그림이 나온 뒤 실제 그림으로 hold 3프레임 전환이 끊겨 보이지 않는지(필요하면 2~4프레임 또는 1프레임 교차 페이드).
- 잠의 숨쉬기 주기(2.5~3초)와 Zzz 사용 여부는 디자인 결정.
- 휘는 꼬리를 스키닝으로 할지는 편집기 `.rev` 경로(계정 필요)를 쓸지와 함께 정한다.
